# Minha jornada no Muay Thai

Site pessoal que conta a minha história no Muay Thai: como comecei em 2023, as competições de 2025 e 2026, a viagem ao Rio de Janeiro e o sonho de lutar na Tailândia.

Feito do zero com HTML, CSS e JavaScript puro, sem frameworks.

## O que tem no site

- Página única com seções: começo, primeira competição (2025), Rio de Janeiro, vídeos de treino, segunda competição (2026) e o sonho de lutar na Tailândia
- Galerias de fotos com ampliação ao clicar
- Vídeos de treino
- Barra de progresso de leitura e animações ao rolar a página
- Layout responsivo, para celular e computador
- Menu de navegação e rodapé com contato

## Tecnologias

- HTML5
- CSS3 (Grid, Flexbox e media queries)
- JavaScript (sem bibliotecas)
- Fontes do Google Fonts (Barlow Condensed e DM Sans)

## Como rodar

1. Baixe ou clone o repositório.
2. Abra o `index.html` no navegador.

Se quiser, abra a pasta no VS Code e use a extensão Live Server para ver as alterações em tempo real.

## Como publicar no GitHub Pages

1. No repositório, vá em **Settings → Pages**.
2. Em *Branch*, escolha `main` e a pasta `/ (root)`.
3. Salve e aguarde 1 a 2 minutos. O link do site aparece na mesma página.

## Como trocar os vídeos

Os vídeos ficam na pasta `videos/` e a lista de nomes está no começo da seção de vídeos do `js/script.js`. Ao trocar um arquivo, mantenha o mesmo nome ou atualize a lista.
